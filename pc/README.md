# GamepadBridge (sisi PC)

Prasyarat: .NET SDK 10, Visual Studio 2026 (atau VS Code), ViGEmBus terpasang.

1. Buka Command Prompt di folder ini, jalankan `setup.cmd`
2. `dotnet test`  -> semua tes harus lulus
3. `dotnet run --project GamepadBridge.Simulator`
4. Buka https://hardwaretester.com/gamepad di browser: tombol/analog akan bergerak sendiri.
